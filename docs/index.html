mnemo — layered long-term memory for LLM agents

An agent starts every session with an empty head. This page shows what it gets handed on wake-up, and why that stays a constant size while the database grows.

This is a browser reimplementation of the same rules the Python library applies — no server involved, everything below runs locally so you can poke at it. Source: github.com/colintea078-prog/mnemo

The problem, in one slider

A long-running agent writes a rolling summary every week. Each one has an equal claim to being always-loaded. Drag to add weeks and watch what wake-up costs.

Write an entry

Writing a third entry tagged summary into core demotes the oldest one. Demoted entries stop loading on wake-up. They are never deleted.
